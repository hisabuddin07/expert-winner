# NOORJAHA

NOORJAHA is a premium Islamic & modest fashion eCommerce platform.

## Features

- React Native mobile app
- Node.js backend
- MongoDB database
- Razorpay payment gateway
- Firebase notifications
- Vendor dashboard
- AI fashion assistant

---

## Frontend Setup

```bash
cd frontend
npm install
npx react-native run-android
```

---

## Backend Setup

```bash
cd backend
npm install
npm run dev
```

---

## Environment Variables

Create:

```bash
.env
```

Add:

```env
MONGO_URI=
JWT_SECRET=
RAZORPAY_KEY_ID=
RAZORPAY_SECRET=
```

---

## Build APK

```bash
cd android
gradlew assembleRelease
```

---

## Build AAB

```bash
gradlew bundleRelease
```
